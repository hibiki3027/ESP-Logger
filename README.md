# ESP Logger

ESP Logger は、ESP32 ベースの車載データロガーです。  
GPS と加速度・姿勢センサーを用いて、走行中の速度、位置、G、姿勢変化などを記録し、スマートフォンやPCのブラウザから確認・保存できます。

サーキット専用機や高価な市販ロガーに頼らず、日常走行・ワインディング・テスト走行などで扱いやすい、シンプルな車載ログ環境を目指しています。

---

## 主な特徴

- GPSによる位置・速度・進行方向の記録
- Bosch製センサーによる加速度・姿勢情報の取得
- スマートフォン対応のWeb UI
- Wi-Fi接続によるブラウザ操作
- ログ開始・停止
- ストップウォッチ表示
- GPS補足状況の確認
- 走行レポートのHTMLファイル出力
- カスタムGPT等を使った走行データ解析に対応
- USB-C給電で動作
- `.bin` ファイルによるアップデート機能

---

## 想定用途

- 車両の走行ログ記録
- ワインディング走行の振り返り
- 速度・G・軌跡の確認
- セッティング変更前後の比較
- 運転練習のフィードバック
- カスタムGPTによる走行解析用データ作成

## システム構成

ESP Logger は、本体内でログを記録し、Web UIから操作します。

基本的な流れは以下の通りです。

1. ESP Logger を USB-C で給電
2. スマートフォンまたはPCから ESP Logger にアクセス
3. Web UIでログ記録を開始
4. 走行後にログを停止
5. HTMLレポートを保存
6. 必要に応じてカスタムGPTなどで解析

---

## 初回セットアップ

初回起動時、ESP Logger はセットアップ用のアクセスポイントとして起動します。

1. スマートフォンのWi-Fi設定を開く
2. `ESP Logger Setup` に接続
3. ブラウザで設定画面にアクセス
4. 使用するWi-Fiまたはスマートフォンのテザリング情報を登録
5. ESP Logger を再起動
6. 登録したネットワークに接続後、Web UIへアクセス

車内で使用する場合は、スマートフォンのテザリングや車載Wi-Fi環境が必要です。

## Web UI

Web UIでは、以下の情報を確認できます。

- 現在速度
- GPS補足状態
- 衛星数
- 日時
- ストップウォッチ

- 姿勢情報

スマートフォンでの操作を前提に、シンプルで見やすいUIを目指しています。

---

## レポート出力

ESP Logger は、走行後にHTML形式のレポートファイルを出力できます。

レポートには以下のような情報を含めることを想定しています。

- 走行日時
- 走行時間
- 走行距離
- 最大速度
- GPSログ
- G情報
- 姿勢情報
- 走行軌跡
- 解析用データ

HTMLファイルとして保存できるため、PCやスマートフォンで開いて確認できます。

また、保存したレポートをカスタムGPTに読み込ませることで、走行内容の解析や改善点の抽出にも活用できます。

---

## 本体の設置方法

車載時は、本体を座席下やセンターコンソール付近など、できるだけ平らな場所に設置してください。

本体の `FRONT` 表示を車両前方に向けて設置します。

正しい向きで設置することで、前後・左右方向のGや姿勢情報を扱いやすくなります。

## アップデート

ESP Logger は `.bin` ファイルを使用したアップデートに対応しています。

Web UIからアップデートファイルを選択し、ファームウェアを書き換えることができます。

アップデート中は電源を切らないでください。

---

## 注意事項

- 本製品・本プロジェクトは運転支援装置ではありません。
- 走行中にスマートフォンやWeb UIを操作しないでください。
- 公道では交通ルールを守り、安全運転を行ってください。
- GPSやWi-Fi環境によって、記録精度や接続状態が変化する場合があります。
- 記録データは参考情報として扱ってください。
